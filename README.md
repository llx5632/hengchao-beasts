# 衡潮群岛 · 本地网页首版

在此目录运行：

```powershell
npm start
```

打开终端输出的 `http://127.0.0.1:5173`。无需安装依赖。验证规则：

```powershell
npm test
```

## 已实现

- 默认玩家对 AI，双方初始各持有全部十五种卡牌，每种一张；收藏与当前对局保存到本浏览器。
- 战斗：秘密选卡并同时亮牌、属性直胜、秘密猜拳、仅胜者行动、两个技能、回血和阻退、独立 HP 与剩余撤退状态、撤退平局、主动投降失卡。
- 拼点：选五张实际卡（可选同种的不同副本）、分别洗牌、只看自己的本次卡、秘密点数及随机点数、模六比较、平手亮牌重比、同卡跳过、五小局、逐局赢卡、同时秘密决定继续/投降、五档罚卡与结果明细。
- 对手始终由基础 AI 控制，自动选卡、选点、出拳和行动。点数与出拳随机；战斗根据公开状态选择技能或撤退。AI 不读取对方未公开的拼点卡来选择点数。玩家可暂离交由 AI 接管自己一侧，再恢复操作。
- “恢复全部卡牌”按钮可将双方收藏恢复为各十五张，并清除当前版本上一场记录。对局赢卡、失卡及不足五张不能拼点规则保留。

## 首版范围

本地首版只需玩家操作自己一侧，无交接屏幕。AI 的秘密选卡、出拳、选点在双方完成前不公开；拼点仅在平手亮牌或小局结束后公开双方卡牌。本地数据不提供针对浏览器开发者工具的防作弊。AI 当前在小局之间始终选择继续。

退出/掉线规则在本地以“暂离 / AI代出”按钮验证。真实远端掉线检测、关闭浏览器后持续运行的 AI、联网权威判定和重连属于联网阶段；本地 AI 在网页保持运行时工作。页面刷新后恢复收藏及未结束对局，并继续由 AI 控制对手。

不包含抽卡、账号、在线匹配或服务器收藏。规则中的回血上限、阻退上限及数值使用当前 GDD 的候选配置，仍可修改。首批十五张均有当前卡面，位于上级 `卡牌/当前卡面/`：十二张新卡与三张修订卡，采用当前名称、基础数值和技能效果，原三张概念图保留。图鉴卡下方可打开完整 PNG；`http://127.0.0.1:5173/cards.html` 查看全套整卡。新视觉待用户审阅。

## 文件

- `dist/data.js`：十五张卡的配置、初始卡、拼点六项。
- `dist/card-art.js`：十五张当前卡面的路径映射；与基础数值分开维护。
- `dist/cards.html`：全套整卡总览；离线版本见 `卡牌/当前卡面/卡面总览.html`。
- `dist/engine.js`：独立规则与状态迁移；UI 不直接修改卡牌基础定义。
- `dist/session.js`：首版双方全卡收藏与玩家对 AI 的默认配置。
- `dist/app.js`、`dist/style.css`：玩家对 AI 的对局及收藏界面。
- `test/*.test.mjs`：关键规则、卡牌所有权与人机首版默认配置校验。
- `server.mjs`：仅绑定本机回环地址的静态预览服务，无外部依赖。

抽卡继续后置。所有卡名、数值及技能以工作区当前 GDD 为设计基线。

本次人机版使用独立的浏览器存档，不载入早期交接屏幕版的收藏及对局；旧存档仍保留。正式获取方向中的五张初始低阶卡不用于本地玩法测试版，抽卡仍后置。

出战展示：拼点与战斗均直接显示完整卡面，包含静态基础值与两个技能；拼点未公开的对方卡仍为卡背。只有战斗模式在卡面下方单独显示剩余 HP 和本局剩余撤退点数，拼点不显示这两个对局状态。
